# Preferences

## Language and Content
- All text content must be in Polish
- Professional and psychological-appropriate tone
- Clear, concise messaging for mental health context

## Code Quality
- Senior-level complexity: High-quality, maintainable, scalable code with advanced best practices
- Clean, efficient, and optimized code
- Follow HTML5, CSS3, and JavaScript best practices
- Semantic HTML structure for accessibility
- Modular JavaScript with modern ES6+ features

## Design Approach
- Mobile-first responsive design
- Use of Flexbox and CSS Grid for layouts
- Consistent color scheme and typography
- Ultra-modern, professional psychological/mental health aesthetic with interactive elements

## Responsive Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## Development Preferences
- Clean, organized CSS with logical grouping
- Reusable CSS classes and components
- Efficient selectors and minimal redundancy
- Focus on performance and fast loading
