# Tech Stack

## Frontend Technologies
- **HTML5**: Semantic markup, accessibility features, structured content
- **CSS3**: Flexbox, CSS Grid, animations, responsive design with media queries
- **JavaScript**: Interactive elements, modern web features, ultra-contemporary functionality

## Constraints
- No CSS preprocessors (Sass, Less, etc.)
- No frameworks (Bootstrap, Tailwind CSS, etc.)
- Vanilla HTML, CSS, and JavaScript only

## Development Tools
- Code editor (VS Code recommended)
- Browser developer tools for testing and debugging
- Responsive design testing tools

## Quality Level
- Senior-level complexity: High-quality, maintainable, scalable code with advanced best practices
- Focus on semantic HTML structure
- Efficient CSS with reusable classes and components
- Modular JavaScript with modern ES6+ features
- Mobile-first responsive design approach

## Responsive Breakpoints
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## Performance Considerations
- Optimize CSS for fast loading
- Use efficient selectors
- Minimize CSS file size through organization
