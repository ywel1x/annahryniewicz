# Dr Anna Hryniewicz — Strona Osobista

Profesjonalna strona internetowa Dr Anny Hryniewicz — doktora nauk medycznych i nauk o zdrowiu, psychologa, psychotraumatologa i pedagoga.

## Opis

Strona prezentuje:
- Informacje o doświadczeniu zawodowym i specjalizacjach
- Ofertę szkoleń i warsztatów dla instytucji
- Współpracę z Poradnią Zdrowia Psychicznego Holisens
- Formularz kontaktowy

## Technologie

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript
- Responsywny design

## Struktura projektu

```
.
├── index.html          # Główny plik HTML
├── styles.css          # Style CSS
├── script.js           # Skrypty JavaScript
├── src/               # Zasoby multimedialne
│   ├── omnie.mov      # Wideo hero
│   ├── zaproszenie.mp4 # Wideo szkolenia
│   ├── sala1.webp     # Zdjęcia
│   └── holisenslogo.png # Logo
└── README.md
```
